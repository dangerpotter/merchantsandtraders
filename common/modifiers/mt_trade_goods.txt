############################################################################################
# MERCHANTS AND TRADERS - TRADE GOODS MODIFIERS
############################################################################################
#
# This file defines all trade goods as modifiers that can be applied to counties, characters,
# or holdings to represent production and trade of various commodities.
#
# DESIGN PHILOSOPHY:
# - Each trade good provides a base monthly income representing its market value
# - Additional modifiers reflect the strategic/cultural value of each good
# - Goods are categorized by rarity and utility (Luxury, Common, Regional)
# - Modifiers are intentionally modest to allow stacking without breaking game balance
#
# INTEGRATION POINTS:
# - These modifiers can be applied via scripted effects (see mt_goods_production.txt)
# - Production levels (poor/modest/rich/abundant) multiply these base values
# - Trade route systems can reference these modifiers for pricing
# - AI systems can check for luxury goods to inform diplomatic behavior
#
# USAGE PATTERN:
# - Apply to counties: add_county_modifier = { modifier = mt_trade_good_silk years = -1 }
# - Check production: county_produces_goods_trigger (see mt_goods_triggers.txt)
# - Stack multiple goods per county to represent diverse production
#
############################################################################################

# FUTURE EXPANSION NOTES:
############################################################################################
#
# PRODUCTION LEVELS:
# - Base modifiers here represent "modest" production
# - Scripted effects will multiply these values:
#   * Poor: 0.5x multiplier
#   * Modest: 1.0x multiplier (base)
#   * Rich: 1.5x multiplier
#   * Abundant: 2.0x multiplier
#
# ADDITIONAL GOODS TO CONSIDER:
# - Gems (diamonds, rubies, emeralds)
# - Copper/Bronze
# - Tin
# - Cotton
# - Sugar (later period)
# - Dyes (indigo, cochineal)
# - Paper/Papyrus
# - Glassware
# - Ceramics
# - Perfumes
#
# MODIFIER STACKING:
# - Counties should receive 1-3 trade goods based on terrain and culture
# - Example: Coastal Mediterranean county might have: olive_oil, wine, salt
# - Mountain county in Persia: saffron, incense
# - Forest region in Rus: furs, timber, amber
#
# INTEGRATION WITH OTHER SYSTEMS:
# - Trade routes can check for production and calculate profit margins
# - AI can be weighted to target counties with luxury goods
# - Events can reference specific goods for flavor
# - Buildings can boost production of specific goods
# - Cultural traditions can grant bonuses to regional specialties
#
############################################################################################
