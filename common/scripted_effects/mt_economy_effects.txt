# This file implements the SUPPLY & DEMAND ECONOMY scripted effects
#
# ECONOMIC SYSTEM OVERVIEW:
# These effects manage the dynamic market economy, updating prices based on
# supply/demand balance, distance, scarcity, oversupply, and seasonal factors.
#
# EFFECT EXECUTION ORDER (typical monthly cycle):
# 1. update_regional_demand_effect - Recalculate what each region wants
# 2. calculate_market_price_effect - Determine prices for specific trades
# 3. apply_market_saturation_effect - Adjust for oversupply
# 4. market_crash_effect / market_boom_effect - Handle extreme events
#
# KEY CONCEPTS:
# - Supply: Local production + imports from trade routes + stockpiles
# - Demand: Local consumption + exports to other regions
# - Saturation: When supply greatly exceeds demand, triggering price crashes
# - Scarcity: When demand exceeds supply, creating profit opportunities
# - Market Balance: The system naturally seeks equilibrium through price signals
