# This file implements the SUPPLY & DEMAND ECONOMY system for the Merchants and Traders mod
#
# ECONOMIC MODEL OVERVIEW:
# The system simulates a dynamic market economy where prices fluctuate based on:
# 1. BASE PRICE: Each trade good has an inherent value (luxury goods vs common goods)
# 2. DISTANCE: Goods become more valuable the farther they travel from origin
# 3. SCARCITY: Regions with low supply see dramatic price increases
# 4. OVERSUPPLY: Markets flooded with goods experience price crashes
# 5. SEASONALITY: Time of year affects agricultural and weather-dependent goods
#
# SUPPLY/DEMAND BALANCING:
# - Each county tracks supply (production + imports) and demand (consumption) for each good
# - Price multiplier = (Demand / Supply) with bounds [0.3x to 3.0x]
# - Multiple trade routes importing the same good will saturate the market
# - Merchants must diversify or find undersupplied markets to maximize profit
# - Regional events (war, plague, harvest) dynamically affect supply and demand
